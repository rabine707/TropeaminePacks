# Locally hosted fonts

DM Sans and Manrope variable WOFF2 fonts, normal style, including the supplied Latin/Latin Extended subsets and Manrope’s Greek, Cyrillic and Vietnamese coverage, from `@fontsource-variable/dm-sans@5.3.0` and `@fontsource-variable/manrope@5.3.0`.

These preserve the existing font family names and weights. They are served by Tropeamine; visitors no longer request the Google Fonts stylesheet or font files. The included SIL Open Font License files must accompany redistribution. No runtime font package or new dependency is required.
